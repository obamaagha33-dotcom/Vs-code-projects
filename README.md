# GCE Study Companion

## About the Project

GCE Study Companion is a web application designed to help Cameroon GCE students revise Mathematics, Further Mathematics, Physics, Chemistry, and Computer Science.

The project aims to make revision more interactive through subject selection, practice questions, answer feedback, and basic progress tracking.

This is an early version that will be improved as development and testing continue.

## Features

- Subject selection for five study subjects
- Interactive practice questions
- Feedback on submitted answers
- Basic learning progress tracking
- Responsive web interface

## Technologies Used

- **HTML** — structures the web pages
- **CSS** — styles the interface and layout
- **JavaScript** — handles interactive features and progress tracking

## How to Run the Project

### Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For development, you can also open the folder in Visual Studio Code and use the Live Server extension.
